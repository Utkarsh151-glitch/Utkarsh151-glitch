## About me

- 🛠️ I build AI-powered web apps end to end: Next.js and React frontends, Node.js and FastAPI backends, and the LLM layer (tool calling, web search, RAG).
- 🤖 Currently building **Devoploy**, a GitHub App agent that reads failed CI runs, proposes a fix and opens a pull request.
- 🏭 Software Development Intern at ASA Industries, where I replaced a 141-column Excel workflow with a production ERP.
- 🎓 B.Tech ECE at SRM University (2028), looking for AI and full-stack internships.
